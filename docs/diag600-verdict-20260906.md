## 判定 = 否定 (按预注册: 无臂满足收敛 ≥2pp 且 3/3 方向一致)

1. **educate 600s 符号混无收敛**: s42 +43.7 / s43 +2.5 / s44 −139.5,
   全在 base 散布内 (educate 自身散布 82.3); 均值 −1.0% 与 6000iter 的
   −2% 同量级但更弱。与 pyvrp 差距: base +9.6% → educate +8.6%, 收敛
   ~1pp, 不达 ≥2pp 门槛。
2. **combo 3/3 全面劣于 base** (+110.0/+13.7/+185.1, 均值 +3.2%):
   educate 与 rebalance **负交互** — educate 挤占迭代预算后 redispatch
   几乎无机会执行 (rb_moves 0/2/0 vs 首轮 rebalance-only 0/2/7),
   cx 分支本身又把主搜索迭代减到 base 的 ~27%。
3. **rebalance-only 600s** (首轮三次复现): 仅 s43 实质 (−126.7,
   3146.46, 三次运行稳定), s42/s44 ≈0 → 1/3 seed 效应, 不构成方向一致。

## 机制归因 (预注册预设的预算竞争问题实锤)

educate/combo 的 iterations 1706-2103 ≈ base 6051-7287 的 **27%**:
每次破坏性教育 (burst + LS budget 300) ~0.8-1.0s, cx rate 0.2 →
600s 内 ~360 次教育 ≈ 300s+ (一半预算) 被教育吃掉。教育成功率仍高
(169-224/330-391, 52-62%) 但轨迹迭代不足 → 净损。**固定迭代口径
(6000iter, 教育免费) vs 时间预算口径 (600s, 教育吃预算) 行为反转**
— 与 09-04 admit 的 6000iter/600s 反转同族: 机制有效性口径依赖。
educate 的 LS budget 300 在时间预算下不可承受; 若要教育在 600s 可行
需 LS budget 降一个量级 + cx rate 降 (参数再设计), 按框架属参数
探索, 不作新机制轮。

## 结论

**600s 组合诊断否定**: 机制组合在 pyvrp 对照口径下不收敛差距 (educate
无净增益, combo 负交互恶化), 形态工程投入无依据。6000iter (200-400s)
与 600s 两口径、单机制与组合、固定迭代与时间预算 —— 全部格子已填:
单轨迹+档案形态对 HGS 的 6-11pp 差距是**形态上限**, 无单机制/轻量
组合可达收敛。**收束路线 3 (论文转轨)**。
