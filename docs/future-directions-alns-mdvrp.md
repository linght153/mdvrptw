# 回归 MDVRP 优化算法框架: 新方向调研 (2026-09-01)

背景: 场景化 vs 短视打平 = 前人结论复现 (Ulmer 2018 / Ichoua 2006 / ScPO),
动态场景化不具独立研究价值 (用户拍板)。论文主线已锚定通用 ALNS 求解框架。
本文档: ALNS 底座下的新方向候选, 基于 2024-2026 文献检索 + 项目已验证结论。

## 保留的已验证结论 (作为新方向的杠杆)

1. ALNS+RVND 引擎质量: pr01 120s gap +1.4%; pr01-05 平均 gap +3.3% vs .res
2. 充分迭代 (50000 iter) 超越官方 .res: pr04 2854.64 vs .res 2958.23,
   距 HGSADC 2815.48 仅 +1.4%
3. 大实例收敛不足: pr05 (240 客户) 120s gap +8.5% → 规模是真实瓶颈
4. 时间预算方差: 120s 预算结果随负载波动 1-2% 不可逐位复现; 固定迭代可复现
5. LLM 生成算子有效 (4-6.8x 加速, 跨实例迁移); 在线 RL 算子选择 4 轮全败 (勿再碰)
6. 顺序迭代无法 GPU 化; 场景级并行用 CPU 多核即可

## 文献格局 (2024-2026, 检索于 2026-09-01)

- 大规模 MDVRP (500-1000+ 客户): 神经方法入场 (DeepMDV arXiv:2411.17080,
  MDVRP1000 gap ~1.1%; NCO 系列), 纯 ALNS 大规模系统研究空白;
  工业需求: MIM 2025 / INCOM 2024 供应链挑战赛 (200 合成大规模实例)
- RL 算子选择红海: PPO-ALNS (JCO 2025), GRLOS (C&OR 2024), LANDS (2025)
- ALNS 算子系统评价: EJOR 2025 "A review and ranking of operators in ALNS"
- ALNS 并行: Spark-ALNS (SciRep 2024), PALNS+deep generative (2025)
- ALNS matheuristic: VRP 通用三阶段 (ALNS 列池+Set Cover, DTU) 活跃;
  纯 MDVRP 上的 ALNS+SP 精化检索无直接命中 → 空白
- HGSADC (Vidal 2013) 仍为 MDVRP 长期 SOTA; ALNS 混合进化有空间

## 候选方向

### A. 大规模 MDVRP 分层 ALNS (500-1000 客户) [推荐主线组件1]
内容: 车场-客户两阶段分解 (聚类分配 → 子问题 ALNS → 迭代精化),
邻居降采样 / 多核并行。
空白: 上述格局; 工业需求明确。
杠杆: 结论 3 (收敛不足实测) 直接支撑分层动机; pr01-33 基准现成。
风险: 算力; 500 客户可行, 1000 需工程优化。

### B. ALNS 列池 + 集合覆盖精化 (matheuristic) [推荐主线组件2]
内容: ALNS 生成高质量路由池 → Set Partitioning 精确重排 (OR-Tools CP-SAT,
免费) → 大规模实例 gap 证明/最优性下界。
空白: 纯 MDVRP 三阶段工作少见。
杠杆: 数学学院背景; 引擎已能产出逼近 HGSADC 的列池 (结论 2)。
风险: 提升 1-2%; 精确部分实现成本高。

### C. ALNS 混合进化框架 + HGSADC 全基准对比 [备选]
内容: ALNS + 种群多样性 (elite pool + 后代教育), pr01-33 系统对标。
杠杆: RVND 单项 +12pp (LS 质量主导); 充分迭代已逼近 HGSADC (结论 2)。
风险: HGS 变体竞争; 需差异化叙事 ("纯 ALNS 底座最小混合达 SOTA" 实证)。

### D. 时间预算方差统计方法 (预算-迭代混合终止准则) [子贡献]
内容: 预算结果随负载波动 → 带统计保证的终止准则/公平对比协议。
杠杆: 结论 4 独家一手数据。
风险: 太窄, 并入 A/B/C 的"可复现性"小节。

## 推荐

A+B 组合: "大规模 MDVRP 的分层 ALNS-matheuristic 框架" —
一个完整故事 (分解 → ALNS 精化 → 集合覆盖精化), 有空白、有正面结果
空间、数学背景契合、全部复用现有引擎。备选 C (冲刺 SOTA 对比表)。
D 作为可复现性小节素材。

## 若选 A+B 的实施路径 (草案)

1. 基准扩展: 下载 fboliveira/MDVRP-Instances (pr01-33 + 大规模集),
   与现有 pr01-05 引擎验证兼容性 (解析器/可行性检查)
2. 分层: 车场分配 (距离/容量感知) + 客户聚类 → 子实例 ALNS → 合并精化
3. 精化: 列池收集 (充分迭代) → SP 模型 (OR-Tools CP-SAT) → 重排
4. 实验: 500/1000 客户 × 多车场 × 与 DeepMDV/HGS 对比 (gap, 时间)
5. 可复现性: 固定迭代终止 + 负载隔离 (沿用结论 4 教训)
