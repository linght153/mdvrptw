## 3. 判定

- **J2(跨口径形态保持)**: d(ge−base) pr15 −2.4 / pr16 −33.6 / pr20 −48.2,
  3/3 方向为负零反向, 但均 < 600s 同臂散布(s 18-83, 时间预算方差红线已知) →
  按预注册记"方向性, 幅度不足"; 无任一实例 d > +s → **无负效**。
  结论: 形态优势跨口径方向性保持; 幅度被迭代预算差(0.44-0.64×)压缩 — 若未来
  压缩教育深度成功(中间档), 600s 幅度有望兑现。

  预算)pr15 +4.5% / pr20 +8.4%(6000iter 口径曾为 6-11pp, pr20 收窄 1.6pp;
  pr15 在 600s 下 base 已近 popcxge, 形态收益被 base 的高迭代数吸收)。
  引擎实现效率差异如实注明(pyvrp C++ vs 本引擎 Python) — 论文对比的诚实定位。
