  archive_mean_jaccard(低=更分散)popdc **3/3 实例低于 pop**(0.589 vs 0.654 /

## 3. 过程观察(记录不设门槛, 供 M2 设计)

1. **质量-多样性张力**: pop(κ=0)质量均值优于 popdc(pr16 −55 vs −44, pr20 −105
   vs −48), 而档案多样性相反(popdc 更分散且略优于 base, pop 比 base 更同质:
   jaccard 0.654/0.672/0.710 vs base 0.612/0.642/0.588)。κ=0.05 的多样性代价
   ≈ 0.2-1.7% 质量。M2 的 κ 档位值得作为显式臂, 预注册死值。
2. **驱逐源重复 → 池坍缩**: pool_final_spread=0.0(8 成员路由集全同)出现于
   5/18 运行(pop 3 次 pr15/p16/p20 各 1-3、popdc 2 次)— 同波扫描刷新多个停滞
   成员时, _select_parent 的 crowding 每次都返回同一档案条目 → 池收敛到单条目
   副本。**M2 前置修复项**: 驱逐源去重(同波内禁重复源 / crowding top-k 随机化,
   消耗 engine.rng 保持确定性)。
3. **墙钟 1.43-1.74× base**(6000iter 固定迭代口径, 公平性不受影响; 单组
   独立重跑 wall 与批内一致 207.8s — 批内均值 337s 系 -P9 并行 CPU 竞争):
   迭代内开销来源未 profile(候选: dc 重算/驱逐重建/轨迹同构日志)。M5 进 600s
   口径前必须压缩(目标 ≤1.2×), 记技术债。
4. **正效机制假说(待 M2 检验, 不作 claim)**: 池级滚动刷新 = 每成员至多停滞
   200 iter 即被档案精英替换(6000iter 内 ~130 次移民), 相当于 base 所无的
   **细粒度档案精英重启流**(6000iter 下 base 无任何重启, archive 只作父代源);
   低成本成员主导锦标赛 + 持续精英移民 = 探索-利用双通道。该假说与既有
   "600s 重启=有效多样性"史一致, 但 6000iter 口径首次出现正效 — 若 M2 重组
   臂增益与刷新叠加, 假说成立性增强。

## 4. 结论与下一步

M1 通过 → **M2 判别实验立项**(A 臂路由继承重组 vs B 臂车场分配继承重组,
6000iter 同口径)。M2 规格必须包含: 驱逐源去重修复(本判定 §3.2)、κ 档位臂、
dc/驱逐的确定性约束。M2 判定 = 轴2 灵魂问题: MDVRPTW 上种群 load-bearing
重组单位是车场分配还是路由。
