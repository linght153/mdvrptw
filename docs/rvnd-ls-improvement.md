# RVND 多邻域局部搜索改进记录

> 2026-08-08 · 触发: 用户指出"局部搜索应该使用更丰富的算子, LS 经
> 验证比大多数算法有效" — 经调查确认原实现仅 two_opt, 与文献
> (Vidal 2013 HGSADC 强在多邻域 LS) 存在关键差距。

## 1. 发现

| 检查项 | 结果 |
|---|---|
| 原 local_search.py | 仅 two_opt_improve (路由内反转) |
| 旧项目 local_search.py | 同样仅 two_opt (记忆偏差: 旧项目丰富的是 destroy 8 算子) |
| 跨路由算子 | 无 (relocate/swap/2-opt*/cross-exchange 全缺) |
| two_opt TW 行为 | 纯距离, 接受 TW 违规移动 (实测 Δ-80 但 TW=20) |

## 2. 实现 (commit 534d556)

- **two_opt TW-aware**: 只接受反转后路由 TW 可行的移动
  (原实现破坏 TW 后靠 _enforce_tw 修复, 浪费搜索)
- **relocate_improve**: 跨路由移动客户 (TW-aware)
- **swap_improve**: 跨路由交换客户 (TW-aware)
- **two_opt_star_improve**: 跨路由尾部重连 (TW-aware)
- **rvnd_improve**: 随机邻域顺序的变邻域下降, 组合全部 4 邻域
- engine 三处 LS 调用统一传 rng (可复现性, commit ba42ee4)

## 5. 结论

1. **LS 是 VRP 元启发式的核心引擎** — 用户判断正确, 文献实证一致;
2. **two_opt TW-aware 单项改进 +12 个百分点** (16.2% → 4.2%),
   消除 LS 破坏 TW 的隐性浪费;
3. **跨路由算子再改进 +2.8 个百分点** (4.2% → 1.4%),
   探索 two_opt 无法到达的解空间;
4. 四轮改进累计: 静态 gap 从 +67-122% → +1-5%, 动态成本降 27%;
5. 论文 v0.5 §4.4 已记录 (四轮改进第 4 项)。
