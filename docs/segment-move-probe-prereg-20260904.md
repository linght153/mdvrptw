# A3 成分探针预注册: 段级移动 + 重定时的 TW 可行率 (2026-09-04)

衔接: 探针1 判定 (docs/connectivity-probe-verdict-20260904.md) 发现 600s 解上
单客户 relocate/swap/2-opt* 的**改进候选 TW 可行率 = 0%** (TW 时间涟漪阻断单移动),
方向结论 = "剩余 gap 需多客户协同 + 重定时级组合移动"。本探针直接测该处方:
在同样 600s 可行解上枚举**段级移动** (段迁移 / 段交换 / 段内搬移) + 全量重定时
的可行性。若可行率显著 > 0 → A3 算子值得实现; 若仍 ≈ 0 → 涟漪在段级同样封锁,
组合级保序移动方向关闭, 转向 B 档 (种群形态)。

## 假设

H-A3: 600s 高质量解上, 段级移动 (一次移动 L≥2 个连续客户, 保序) + 重定时后,
存在非零比例的**净距离改进且 TW 可行**候选; 且可行率随段长 L 单调上升
(协同效应: 段越大, 一次解除的时段/负载压力越大, 越可能穿透涟漪)。

机制对照 (探针1 已测基线): 单客户 relocate/swap 改进∩TW可行 = 0/全部。
2-opt* (= 尾段交换特例) 同样 0% — 故段交换并非显然可行, 本探针是真正的新证据。

## 算子定义 (全部保序, TW 检查 = 受影响路由全量重算调度零违规)

1. **seg_relocate** (跨路由段迁移): 路由 A 连续段 S[p..q] (长 L) 迁入路由 B≠A
   位置 pos。容量: load_B + dem(S) ≤ cap (A 侧自动下降); A 侧删段后必然零违规
   (时间只提前, 等待吸收, 无需检查 — 探针内断言验证)。B' 全量重定时检查。
2. **seg_exchange** (跨路由段交换): A 段 S_a ↔ B 段 S_b (A≠B)。容量: 互换后
   双方负载 ≤ cap。两条新路由各自全量重定时检查。
3. **or_opt** (段内搬移, 经典 Or-opt 推广): 段 S[p..q] 在同路由内移到位置
   t ≠ p (删段后插入, 排除原地)。容量不变。

段长域 L ∈ {2,3,4,5} (relocate/or_opt); seg_exchange 段长 L ∈ {2,3}
(候选对数量 O(n⁴), 先限两档控预算; 若显著再扩)。

## 方法 (与探针1 同口径, 结果可直接对比)

- 输入: results/connectivity_{pr15,pr20}_s42_routes.json (600s s42 可行解, 已存在)
- 距离: 受影响路由全量重算 (dm 求和), 净变化 < -1e-9 → **改进候选** (improve)
- TW: 仅对改进候选做检查 (探针1 口径: tw_ok_rate_of_improve); 全量 `_route_tw_excess`
  == 0 判可行; 改进候选 > 20000 时抽样并记录 checked (预期远低于此)
- 输出字段与探针1 对齐: total / cap_pass / improve / tw_ok / tw_checked +
  各段长分块 + tw_ok 候选净改进分布 (min/median/max)
- 对照基线 (探针1 已测, 不重跑): relocate / swap / 2-opt* 的 tw_ok_rate = 0%

## 判定阈值 (pr15 + pr20 合并计数)

- **支持 A3**: 三算子改进∩TW可行候选总数 ≥ 30 且任一算子可行率 ≥ 0.5%
- **边缘支持**: 总 tw_ok ∈ [5, 30) — 看净改进量级, 若 max 改进 ≥ 0.5% 总成本
  也视为支持 (存在少数高价值穿透点即可驱动实现)
- **否定**: 总 tw_ok < 5 (≈ 单移动 0% 的噪声级) → 段级保序移动被涟漪封锁,
  A3 组合级移动方向关闭

附加机制报告: tw_ok 随 L 的分布 (验证协同效应假设), seg_relocate A 侧删段
零违规断言的检查计数 (确认推理), 运行 wall 时间。
