# 600s 组合诊断预注册 (2026-09-06): 机制在 pyvrp 对照口径下是否收敛差距

衔接: 方向② verdict (educate 在 6000iter = 方差压缩 −2% 但不达门槛,
散布 44/26 vs base 89/81) + 方向① verdict 600s 扩展 (both-600s pr20
pen 3/3 降, s43 cost −4.8% 实质, 记录性)。**方法学盲区**: 全部机制
A/B 在 6000iter (200-400s 墙钟) 判定, pyvrp 对照在 600s (~7000 iter +
重启)。600s 曾反转 6000iter 结论 (admit, 09-04 fdcd2ce: 600s 重启 =
有效多样性)。本诊断问: educate / educate+rebalance 在 600s 口径是否
把与 pyvrp 的差距推向收敛 → 决定是否投入全形态工程。

## 定位 (非严格 A/B, 是投入决策诊断)

600s 口径 3-seed 配对散布大 (base-600s pr20 跨 seed 155+), 无足够
判定力做门槛判定; 且 600s 环境敏感 (±1.6% 整批漂移) → **同批串行
重跑全部臂** (配对必须同环境)。诊断输出 = 差距收敛信号, 不是机制
有效性 claim。

## 设计

- 预算 600s, CONFIG = dump_base600s_routes (stagnation 300 + 重启),
  串行独立进程, 同批跑。
- 臂:
  - base: 600s base (同批重跑, 环境配对)
  - educate: + educate_mode=deep (burst 0.20 / max_iter 1 / ls 300)
  - combo: educate + rebalance_mode=both (interval 200)
- 实例: 阶段 1 = pr20 × s42-44 (9 组 ≈ 1.5h); 阶段 2 (仅阶段 1 有
  信号时) = pr15 同 9 组。
- 输出: results/diag600_ab/: 每组 cost + educate 统计 (attempts/
  success) + rebalance 统计 (passes/moves) + 结构指标 (mismatch_
  penalty / geo_consistent_frac) + routes dump。

## 判定信号 (预注册)

对每臂报 3-seed 均值与散布, 以及 vs pyvrp-600s 均值 (pr20 2975.09/
2976.19/2973.92 → μ 2975.07; BKS 2983.78) 的差距:

- **支持形态工程投入** = 存在臂 (educate 或 combo) 满足: ① 均值
  差距相对同批 base 收敛 ≥2pp (如 base +6% → 臂 ≤ +4%), 且
  ② 方向一致 (3/3 seed 臂 ≤ base) 或散布压缩使 3 组全部优于 base
  最差 seed。
- **否定** = 无臂满足 (差距不收敛) → 单轨迹+档案形态在 600s 也到
  天花板, 形态工程投入无依据, 收束路线 3 (论文转轨: 机制研究 +
  结构诊断方法学定位)。
- 附带记录: educate 在 600s 下 iterations/教育次数 (教育慢 10x,
  600s 预算内教育预算竞争是否使轨迹质量受损 — 若 educate 600s
  反而差于 base 且 iterations ≪ base, 归因于教育迭代预算竞争)。
