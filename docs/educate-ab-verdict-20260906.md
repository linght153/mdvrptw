## 第 1 级 机制生效 = 支持 (全过)

- 教育成功比例 57-83% (pr15 948-969 / 1138-1182; pr20 654-719 /
  1160-1220 attempts) — cx 后代几乎总能被 burst 教育改进 (cx 后代
  质量低 → 教育拉回空间大)。
- novel_route_keys 26,366-30,426/组 (~23 键/后代, 档案池外新路由键
  海量) — 教育持续产出结构。
- 档案多样性 ≥ cx: archive_distinct_routes 87-114 vs cx 72-106;
  成员间平均 Jaccard 距离 0.76-0.82 vs cx 0.37-0.54 (距离, 越大越
  多样) → 教育臂档案结构多样性显著高于 cx。

## 第 2 级 质量转化 = 否定 (按预注册门槛, 硬屏障)

- **vs base**: pr15 3/3 负、pr20 3/3 负 (6/6 方向一致, 历史首次) 但
  幅度双不足: pr15 均值 −64.7 < base 散布 89.3; pr20 均值 −43.1 <
  散布 80.7 → 幅度 < 同臂散布, 按预注册不构成支持。
- **vs cx (控制交叉, 教育增益)**: 两实例符号混 (s44 反号 +47.5/+48.5
  — cx s44 偶发极好 2534.59/3212.36) → 教育相对 cx 无稳健增益。
- 记录性观察: educate 自身散布 (44.2/26.2) ≪ base (89.3/80.7) ≪ cx
  (204.0/50.3) → **教育压缩 seed 方差**: 差 seed 被拉起 (pr15 s42
  base 2674.88→2547.30; cx s43 2738.56→2537.91), 好 seed 无增益或
  微损 (s44 型)。与 09-05 admit 教训同构但方向相反: admit 是差 seed
  "免费午餐" 假象, educate 是差 seed 被教育真实拉回 + 好 seed 无增量。

## 结论

**方向② (破坏性教育) 机制成立、质量转化不达判定门槛 → claim 否定**;
与 09-05 交叉教育全族 (cx/pdiv/div/admit, 符号混或零) 相比, educate
首次给出 vs base 6/6 方向一致 + 方差压缩的结构性证据, 但幅度 < 门槛,
且相对 cx (同配置去教育) 无稳健增益 — 教育把每个 seed 拉到同一
"教育吸引域" (pr15 ~2540-2580 / pr20 ~3235-3260), 该吸引域高于 base
均值 ~2% 但距 pyvrp (pr15 2423-2439 / pr20 2974-2976) 仍差 5-8pp
(形态级)。

## 方向含义 (两方向闭合后的收束)

1. 方向① (单客户粒度分配修复) 空转 + 方向② (单轮 20% burst 教育)
   方差压缩但无质量转化 → **单轨迹 + 档案形态内, 单机制升级线收束**
   (与 09-04/05 全族一致: 任何单点机制 ≤ 方差级效应)。
2. 残余形态差 ~5-8pp 需要: 教育轮次/破坏规模参数空间 (burst_ratio
   >0.2、多轮教育) 属参数探索而非机制跃迁, 按框架不再叠; 真正的
   候选只剩全 HGS 形态复刻 (种群 + 罚域 + 教育循环, 以 pyvrp 为
   标尺逐组件对照) 或论文按 600s 平台表 + pyvrp 对照 + 机制研究
   诚实定位。
3. 记录: cx 家族本身是 seed 方差放大器 (pr15 散布 204) — 09-04/05
   cx 无收益结论的散布解释强化; educate 是方差压缩器, 两者档案
   多样性均高 (div 机制) 但质量行为相反。
