## 瓶颈分布 (后续算法改动的对照组)

1. **规模是主瓶颈**: ≤96 客户 gap 1.1-3.7%; 144-216 客户 3.1-11.8%; ≥240 客户
   6.4-32.5% — 收敛不足 (120s 内迭代数随实例规模骤降: pr20 288 客户 120s 仅 ~百迭代)。
2. **宽窗族在同等规模下更难**: 288 客户 pr06/pr10 (窄, 每场 5-7 辆) 12.2-12.7% vs
   pr16/pr20 (宽, 每场 4-6 辆, 负载率 87-94%) 21.2-32.5% — 车辆稀缺 (负载率高) 与
   长路由传播叠加; 难度 = 规模 × 车辆稀缺, 不单纯是窗宽。
3. **pr15/pr20 std 大 (163-173)**: 时间预算方差 + 收敛不稳定实例, 报告需注明。
4. 参照用时: MDFIHA CPU 单实例 γ·t ≈ 22-1494s (10 runs) — 我们 120s 预算平均
   gap 8.72% 的对比语境; 论文若报 gap 需同时报预算与硬件。
