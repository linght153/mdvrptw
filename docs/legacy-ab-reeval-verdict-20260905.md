## 判定 (按计划条款)

1. **admit 无任何稳健效应**: pr15 −1.62 (靠 s42), pr20 +0.22 (符号混且含
   +4.21pp 大正 = admit 比 base 差 4.2%), pr06 +0.48 (符号混)。三实例三
   口径符号不一致 → 09-04 "admit 6000iter 免费午餐 3.7pp"、"div 收益载体
   = admit 准入" **作废** (s42 base 卡死假象确认, pr20 s44 反向大负证明
   放宽准入甚至可在混沌中显著有害)。
2. **div 无跨实例稳健效应**: 均值 [−1.66, +0.19, −0.44, −0.40] 跨实例不
   一致; pr15 三 seed 全负但剔除 s42 后 −0.72pp、配对 t −1.69 (n=3 不显
   著) → population_ab 判定 "H4 部分支持 (pr15 −1.81pp 稳健)" **降级为
   无稳健证据**; "价值域 = 坍缩受困宽窗大实例" 表述无统计支撑。
3. **cx 无稳健效应 (H5 否定存活且强化)**: 散布 ±6pp (pr15 s43 +5.92) 无
   方向 → "该最小交叉形态无效" 存活, 理由从 "打平 +0.08pp" 修正为
   "seed 散布爆炸无方向"。
4. **pr06 窄窗 "多样性不是免费午餐" (div/cx 负) 作废**: 3-seed 符号混
   (div +1.14/−0.59/−1.74, admit +1.96/−0.24/−0.27) → s42 窄窗负也是
   单点。
5. **机制侧幸存**: 档案多样性机制本身生效 (去重列 ×1.4-1.6、Jaccard 缓解
   — 档案状态观测不涉解质量 seed 散布) 但**无质量收益转化** → 档案多样性
   方向 (div/cx/admit/A2) 整体关闭 (与 score 解耦判定一致)。
6. **不涉复核范围 (存活)**: cur/d1/d2 6000iter 逐位=base (机制性);
   A2 fitness 裁剪关闭 (无效应可归因); 600s 口径全部结论 (重启价值判别、
   平台数字、探针系列底座 — 单臂/枚举类)。
7. **口径落定**: 6000 iter 与 600s 均用 base 默认; 档案侧全部 config
   (archive_diversity/fitness_dc/admit_relaxed/population_crossover) 维持
   默认关 — 无任何翻默认依据。

## 方法学教训 (复核版)

- 配对 t 检验 n=3 下, |均值| ≤ 1.7pp 一概不显著 (此引擎 seed 散布 2-3.5%);
  "三 seed 全负" 的符号一致性在单点拉动下无信息量 — 报告须含配对差逐点
  值 + 剔除最值敏感性, 而非均值/符号。
- 单实例 "价值域" claim (如 div 只对 pr15 类实例有效) 需要实例族内 ≥2
  实例 × ≥3 seed 才可提; 单实例效应一律按 seed 假象处理直到反证。
