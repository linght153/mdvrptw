## 机制定义 (实现即此语义)

1. **多样性裁剪 (archive)**: single_objective 模式满容时: ① 按 cost 升序贪心
   保留, 候选与已保集合的**路由 Jaccard 距离** (1 − |Sx∩Sy|/|Sx∪Sy|, 路由按
   (depot, seq) 键) 最小值 < threshold (0.2) 则跳过; ② 保不满 capacity 时按
   cost 从被跳过者补齐。距离缓存: 条目 meta["route_keys"] 惰性计算。
2. **路线复制交叉 (engine 迭代类型)**: 每迭代以 rate=0.2 (archive ≥2 且随机)
   触发: 父代 A = crowding 选择, 父代 B = 随机另一条 (路由集不同); 后代 =
   A 路由随机序 × 继承率 0.6 (车场车辆数上限内) → B 不冲突路由 × 0.6 →
   未覆盖客户 greedy_cost_tw 修复 → RVND 教育 (ls_max_iter) → 走公共
   accept/archive 路径。交叉迭代不更新 selector 权重 (学习状态少一次更新,
   文档注明)。TW/覆盖/车辆数可行性由公共兜底链保证。
3. config 键默认 False/关 → 默认行为逐位不变 (锁存测试 + 116 PASS 回归)。

## 判定阈值

- 档案多样性 (机制有效性检查): div/cx 臂最终档案去重列数 ≥ 2× base (pr20
  至少 59→≥100 列量级或同量级相对提升), 否则多样性修复未生效 → 结果无效。
- 主判定 (pr15/16/20 × 3 seeds 均值 gap):
  - cx − base ≤ −1.5pp → H5 成立 → 立项: 混合进化主线 (档案多样性 + 交叉 +
    教育), 后续做交叉率/继承率/教育深度消融 + pr01-20 全表;
  - −1.5 < cx − base ≤ −0.5pp → 弱正: 机制方向对, 参数/教育需强化 → 继续调
    (继承率/双亲选择/教育迭代数), 再判;
  - cx − base > −0.5pp → H5 否定 → 该最小交叉形态无增益 → 关闭或换形态
    (如 SP 教育替代 RVND 教育) 前不再重复。
- div − base: 单独报告; ≥0.5pp 说明多样性本身是质量杠杆 (档案挤压真实存在),
  ≈0 说明它是交叉前置 (与 H4 预期一致)。
- pr06 对照: 若 pr06 的 cx 增益 ≥ 主实例 → 收益非紧车队特异, 解释修正。
