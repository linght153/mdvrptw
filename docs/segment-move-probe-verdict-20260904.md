| pr20 宽窗 288 (+6.50%) | 2 / 0 | 1 / 0 | 5 / 0 |

段长分块 (L=2..5, exchange 2x2..3x3): 全部 tw_ok = 0, 无任何 L 例外。
A 侧删段零违规断言: 100/100 通过 (删除段后剩余路由时间只提前, 等待吸收 — 推理成立)。

## 判定: 否定 (按预注册阈值)

pr15+pr20 合并 tw_ok = 0 < 5 → **保序段级移动 + 重定时无法穿透 TW 涟漪**,
A3 组合级保序移动算子不值得实现。H-A3 的"可行率随 L 上升"假设同样否定
(所有 L 均为 0)。

## 比否定更强的机制发现: 改进候选枯竭形态分叉

与探针1 (单客户移动) 基线对比 (同解同口径):

| 实例 | relocate 改进/tw | swap 改进/tw | 2-opt* 改进/tw | 段级合计改进/tw |
|---|---|---|---|---|
| pr15 | 11 / 0 | 3 / 0 | 0 / n/a | 2 / 0 |
| pr20 | 13 / 0 | 6 / 0 | 1 / 0 | 8 / 0 |

1. **宽窗紧车队 (pr15/pr20)**: 段级移动连**距离改进候选都枯竭** (2-8 个, 低于
   单移动的 11-20 个) — 600s 解不只是单移动局部最优, 已是**保序段级移动局部
   最优**。ALNS 的 ruin-recreate (随机删簇+贪心重插) 在长跑中已磨平一切
   "保序局部调整"空间。
2. **窄窗 pr06**: 段级距离改进候选丰富 (161 个, 高于单移动) 但 **0 个 TW 可行** —
   窄窗下任何插入都推爆时间窗, 涟漪在段级同样全封锁。
3. **三方合流**: 单移动 (探针1, 改进∩TW=0) + 保序段移动 (本探针, 改进枯竭或
   ∩TW=0) + 路由池精确组合 (SP 探针 H3, 增益 ≤0.015pp) → 剩余 gap (pr20
   +6.5%) **不在"现有路由结构的局部或组合调整"空间内**。新列=新路由结构必须
   被"生成", 而不是从现有路由保序重排而来。

## 边界 (如实标注, 勿过度外推)

本探针只测了**保序**移动 (段内顺序不变、受影响路由除插入外不重排)。未测:
段翻转插入、段迁移+目标路由整体重排 (教育式精化)、跨实例多段同时迁移、
以及"TW 可行但距离不降"的接受 (引擎贪婪档案制下无意义)。这些形态若未来
要做, 需重新预注册, 不得引用本否定当预判。

## 方向结论

- **A3 (组合级保序移动算子) 关闭** — 与轨迹内杠杆 (软容量/逃逸)、邻域级
  (单客户移动)、列池级 (SP) 形成一致闭合: 该引擎在宽窗紧车队族的瓶颈
  = **结构生成能力**, 不是移动空间连通性。
- **B 档获得支持信号**: 教育算子 (后代/新路由深精化)、真种群 + 多样性
  fitness、结构互补双亲交叉 — 这些机制的共同点是**生成档案里不存在的新
  路由结构**, 与本次"新列必须被生成"的结论直接对齐。下次探针应测
  "教育生成的新路由是否落入 SP 池的 81 列之外"。
- pr06 窄窗上的 161 个 TW-死改进候选再次确认: 窄窗族瓶颈是 TW 自身结构,
  与宽窗紧车队 (结构生成) 是不同机制 — 支持按窗宽×负载率分域处理的方法论。
