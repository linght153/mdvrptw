## 判定: A1+教育线关闭 (主线), 不满足预注册"支持"条款

"支持"要求末值 ≤−0.3pp **且后 3 轮仍在下降** — 末值 −0.3797pp 达标但
r13-16 完全平台 (700+ 教育列零收益), 形态饱和 → **不判支持**。按预注册
精神 (支持条款的"未饱和"要件), 判定**关闭**: 教育列池+SP 跳板形态在
pr20 的收益上限 ≈ **0.38pp**, 且以 6 轮饱和告终。

## 成本账 (A1+教育 vs A2 的性价比决定性证据)

- 教育线: 0.38pp / (2×600s 档案资产 + 278s 曲线 + 后续每轮 ~35s)
  = **~0.2pp 每 600s 级投入**; 破局稀有性 = 2521 条教育列仅 3 次破局
  (~1/840 列), 破局列 = 单列替换 (与列池外探针同构)。

  且 pr15 达 −1.81pp。**A2 性价比高一个量级** → 研究重心确认转 A2。

## 机制结论 (写入论文诊断的素材)

1. 教育列生成能力真实但**尾部稀有**: 组合起点×RVND 确实能发现档案池外
   的好列 (r8-10 三次破局), 但好列密度 ~1/840, 且每列只值 ~0.1pp。
2. 阶梯饱和 = 教育列源随池累积而枯竭: 破局后回流 SP 解短暂提升双亲质量
   (r8→r9 加速), 但新盆地列发现一次后, 后续教育重复探索已闭合空间。
3. 与 A3/SP/cx 合流的完整图景: 单轨迹 ALNS 平台 = 结构生成稀缺; 教育是
   唯一实证能生成新结构的机制, 但其发现率低到不足以支撑平台突破
   (0.38pp 上限 ≈ 剩余 gap 6.5% 的 6%), 且依赖昂贵的多轨迹档案资产。
4. 边界: 曲线为 pr20 单实例; 教育作为**种群内嵌组件** (HGSADC 式, 每代
   教育少数后代且种群持续演化) 的形态未测 — 本判定只关闭"离线教育列池
   +SP 跳板"形态, 不预判种群内嵌形态 (若 A2 后仍要追, 需重新预注册)。
