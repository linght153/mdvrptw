## 判定

- **H-F 否定** (罚域盆地存在性, FIS 前提): 档案口径 pr15 符号混 (+7.03
  大差)、pr20 混; 末端修复口径含 +43pp 离群与一次修复失败 (12 轮修不回)。
  单轨迹纯罚演化 6000 iter 无稳健收益 — 只在 base 卡死 seed (s42) 偶发
  逃逸 (−2.8~−3.1pp), 在 base 已好 seed 无增益或大差。**罚域穿越方差 >
  hard**, 穿越偶发有效 ≠ 机制价值。单轨迹 FIS 两形态 (软容量 v2/播种、
  纯罚不播种) 全部关闭; 种群 FIS 无单轨迹层面的盆地存在性证据支持。
- **H-P 否定** (互补双亲交叉): pr15 不达门槛 (vs base 混, vs cx 大混
  [−4.24~+5.47]); pr20 三 seed 一致小负于 base (−0.27~−1.82pp, 均值
  −0.97) 但幅度 <2pp 且配对 t 不显著。双亲结构互补不是 cx 失效主因
  (或交叉教育整体天花板低于 2pp 门槛)。
- **E 机制叙述部分支持、质量转化无证据**: 互补双亲在线教育**高频生成**
  档案外新结构 (每后代 ~13 键 ≫ 离线 ~1/840 破界) — "结构生成规模化"
  机制成立; 但新结构高产 ≠ 质量收益 (P 无稳健改进) → 瓶颈修正:
  **平台缺口不是"新结构生成存在性", 而是"新结构 → 质量改进的转化"**
  (海量新路由键大多不被 LS/接受链转化为改进)。

## 综合 (方向空间收窄)

1. 交叉教育族 (cx/pdiv/div/admit/离线教育列池) + 罚域族 (软容量 v2/纯罚)
   在 6000 iter 充分迭代口径**全部无稳健质量收益** — 结构生成候选三条路
   全闭。09-04 教育列 "0.38pp/878s" 与本次 pdiv 新键高产共同说明:
   **结构新颖性供给充足, 缺的是把新颖结构变成低成本解的机制**。
2. 平台叙事维持: 600s/6000iter 双口径 6.5-11.5% gap (pr20, BKS 2983.78),
   邻域级 (单移动/段级) 与组合级 (SP) 与生成级 (交叉/罚域) 三族机制均已
   探明无稳健杠杆 → 平台性质 = "可行解空间的高质量区域在现有搜索机制下
   不可达", 与文献 HGSADC 系机制的差距需要**全形态复刻级**实验才能排除
   (当前各最小形态均负), 单点形态无捷径。
3. 保留下来的动作: ① 全形态 HGSADC 复刻 (大工程, 需用户拍板) ② 转向
   问题结构侧 (宽窗紧车族的解空间几何分析, 找"高质量区域为何不可达"的
   结构原因) ③ 承认平台并转向论文口径工作 (600s 平台 vs BKS 表作为
   "本算法水平" 诚实定位)。
4. 代码留存: crossover_pair diverse / softfix 臂 / novel 计数 / last_solution
   暴露 — gated 默认关, 138 PASS 锁存。
