## 核心发现 1: ⚠️ 6000 iter 单 seed A/B 不可判定 (方法学红线)

**base 同臂跨 seed 散布 2.3-3.5%**: pr15 {2674.88, 2585.62, 2600.94}
= 3.45%, pr20 2.49%, pr16 2.28%。而 09-04 全部档案侧"收益" (admit
−3.54/−3.69, div −0.70 均值, cx 等) 都落在 ±3.5% 混沌带内:

- admit s42 −3.54/−3.69pp vs **s43 −0.13/+0.15pp** → 收益消失。
  s42 恰是 base 最差 seed (pr15 s42 2674.88 比 s43 差 3.4%) → 09-04
  \"admit 免费午餐 3.7pp\" = base-s42 卡死假象 (admit 逃出同一盆地,
  换个 seed base 自己就到那)。
- div 3-seed 均值 pr15 −1.66 / pr20 −0.44 / pr16 +0.19pp, per-seed
  散布 ±1~3.5pp → 无稳健证据; population_ab 判定的 div 收益 (当时均值
  −0.70pp) 由 s42 单点拉动, 需作废重估。
- pr15 s42 div == admit 逐位 (2580.10) 而 pr20 s42 div (3209) ≠ admit
  (3185.89) — 裁剪机制在混沌中无一致方向。

## 核心发现 2: score 通道 (09-04 selector-准入耦合归因) 整体不成立

- act (score=可行即 2, 权重恒平坦 ~2.0) 与 admit 权重形态相同, 结果却
  s42 差 3.2pp (pr15 2664.99 vs 2580.10); act 与 base (权重倒置地板态)
  权重形态相反, 结果却相近 → **权重形态 ↔ 结果无因果** (6000 iter)。
- qual (P&R 改进阶梯) pr15 s42 −1.51 / pr20 s42 −1.58, 排序跨实例反转
  (pr20 act>qual, pr15 qual>act) → 无一致机制信号。
- 机械归约 (代码审查全链): 6000 iter 下 cx 关、重启/深破坏阈值不可达、
  SearchContext 无消费者、父代 = crowding 退化 = 恒取档案最优、
  档案内容 (top-20 成本) base/admit 集合恒等 → 臂间唯一差异 = score
  行 → 但 score 差异只在 s42 表现为\"收益\" → **无真实效应可归因**,
  \"selector-准入耦合\" 作为机制主张第四次作废 (这次是釜底抽薪:
  效应本身是 seed 假象)。

## 判定

- H-A (score 通道载体): **否定** (act s42/s43 均未达 admit 收益 60%;
  admit 自身 s43 无收益)。
- H-A′ (完备性 pr06): act +1.57 ≈ admit +1.96 同向负 — 但 base s42
  亦可能为窄窗\"好 seed\", 该控制无判别力 (同混沌带内)。
- H-C (质量阶梯不足): s42 不支持 (qual −1.51 显著偏离 base) 但 s43
  未跑 → 无证据, 关闭。
- H-B (600s 两全): pr20 600s act = **3157.01** (sp_pool_pr20_s42_scoreact.json)
  ≤ base 3177.86 ×1.004 ✓ 且 < admit 3253.24 ✓ — 条款通过: act 不损 600s
  重启多样性, 单点略优于 base (−0.66pp)。⚠️ 单 seed 弱证据 (今日方法学
  红线), 定性为\"act 在 600s 无碍且可能略优\", 不作机制 claim。

**探针关闭**。score_scheme gated 保留 (act/qual 语义未来多 seed 实验
可复用), 默认不变。6000 iter 口径 workaround 修正: admit 不再有依据 —
**6000 iter 用 base, 600s 用 base** (原\"6000 iter 用 admit\"作废)。

## ⚠️ 方法学教训 (全项目红线)

1. **固定迭代口径单 seed A/B 不可判定**: 确定性引擎 + 混沌动力学 →
   同臂 seed 散布 ±2-3.5% ≫ 多数机制\"收益\" (0.2-3.7pp)。09-04 全天
   十二探针多数单 seed (s42) 判定 → 其中涉及臂间对比的结论全部需
   ≥3 seed 复核 (div/cx/admit/cur/d1/d2 系列); 单臂平台/枚举类结论
   (连通性可行率、SP 上界、段级枯竭、教育曲线) 不涉臂间差, 底座仍成立。
2. 判定门槛须预注册为 **≥3 seeds × 均值差 > 同臂 seed 散布** (配对
   比较), 单 seed \"−3.5pp 显著\" 是陷阱 — s42 base 卡死型 seed 会
   系统性高估任何\"逃逸\"类改动。
3. 引擎确定性 (同 seed 逐位复现) 已四次验证, 非方差来源; 方差 = seed。
