## 机制诊断 (λ 谱 + 温度曲线假象)

1. **λ0 = obj0/n 量纲病态**: mult=1.0 (λ0=20.1) 比穿越阈值大 ~300 倍;
   λ 档扫描 (mult 1.0→0.003) 显示只有 mult=0.003 (λ0=0.06) 在 600iter
   出现 1 次采纳。
2. **⚠️ 600iter 档位诊断 = SA 温度曲线假象 (方法学教训)**: acceptance.py
   `cooling_rate = exp(ln(t_end_ratio)/max_iterations)` — 温度曲线依赖
   总迭代数 → 600/700/6000 iter 的接受路径不同 (实证: 同 seed 同 config
   仅 max_iterations 不同, 600=采纳 / 700=无)。**档位/机制诊断必须与
   正式口径同迭代数**, 小迭代数诊断结果不可外推 (本探针 600iter 的 1 次
   采纳是 600 温度曲线的产物, 6000iter 下不存在)。
3. **6000iter 下 λ∈{0.06, 20} 全谱无穿越**: violation_iters 大 (pr20
   963-1589) 但罚后全被拒 — 违规解的距离节省 < λ×excess 即使 λ=0.06
   (excess 数百→罚数十, 而 TW 违规的边际距离收益 < 罚) → **无"低罚
   高省"违规盆地**: TW 涟漪结构 (09-04: 违规移动距离改进候选枯竭) 在
   罚域空间的投影 = 违规盆地没有净收益。pr16 违规候选极少 (10-37/
   6000iter): 涟漪主战场在罚域甚至无入口 (修复算子 TW 门严)。
4. SA 单轨迹接受框架与罚域穿越不匹配的独立证据: 即使 λ→0 (罚域≈无
   约束), 轨迹也不滞留违规态并周期性修复获益 — 修复解 (拆路由重插)
   成本高于轨迹, 锚回无利。

## 结论

**TW 罚域单轨迹 (播种 + SA 罚后接受) 在 6000iter 主口径无穿越 → 机制
格全部填完, 探索史收束**。与 H-F (容量罚域) 一致: 罚域单轨迹穿越在
本引擎接受架构下不是可行杠杆; HGS 的 time-warp 价值在种群+教育的
组合语境, 单轨迹版无此机制。方向含义: 单轨迹形态对 HGS 的 6-11pp
差距 (结构差异分析) 至此有完整机制覆盖: 容量罚域 ✗ / TW 罚域 ✗ /
教育 (固定迭代有效果但 < 门槛) ✗ / 时间预算口径教育净损 ✗ / 分配
重平衡 ✗ → 打平路径只剩全 HGS 形态工程 (2-4 周) 或论文转轨
(机制研究 + 结构诊断方法学)。

## 附带: 方法学三教训 (写论文/后续必守)

1. SA 温度曲线依赖 max_iterations → 任何涉及接受的机制, 其小迭代数
   诊断与正式口径结果可能不同, 诊断必须同迭代数。
2. 罚域 λ0 量纲: obj0/n 对 TW excess (时间单位) 病态 ~300 倍; λ 需按
   违规量分布校准, 不能按目标/客户数粗估。
3. violation_iters 类计数必须区分"候选被罚"与"穿越发生" (CC 预警 →
   实证), 机制生效判定应以采纳/轨迹侧统计为准。
