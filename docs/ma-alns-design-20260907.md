分支: `feat/axis2-memetic-alns`(主线 308e846)。改进完成并经预注册口径测试获得
好成绩后才合并主线。配套: docs/ma-alns-m1-spec-20260907.md(CC 实现规格) +

## 1. 决策背景(为什么是轴2)

- 单轨迹形态机制格全填(softtw-verdict-20260906): 容量罚域 ✗ / TW 罚域 ✗ /
  教育(固定迭代幅度不足、时间预算净损)✗ / 分配重平衡 ✗ / 交叉族 ✗。
- structure-diff-verdict: 自产 vs pyvrp 差距 6-11pp = **划分/成员组合盆地不可达
  + 车场分配强吸引子**(LS 收敛对照判别), 非 LS 技术差。
- 文献 2024-2026 主旋律 = HGS 平台化 + LNS/ALNS 作内层: AHGSLNS (arXiv
  2402.18903, GA×LNS 多属性 VRP)、HGS-IRP (EJOR 2025, 击败 ALNS 系基准)、
  PR-ALNS (Evolutionary Intelligence 19:98, 2026, MDVRPTW 最强 ALNS 系,
  距 HGSADC ~0.1% 但需 30 runs × 60min/实例)。
- 推论: 换壳不换形(VNS/TS 同属单轨迹)无出路; 需要**种群+多样性贡献+重组**外层;
  ALNS 内核保留为破坏/重建/精化引擎。经典 MDVRPTW pr 基准上"种群壳包 ALNS"的
  混合未见文献先例 → 定位空间真实存在。

## 2. 证据格 → 设计约束(设计的地基, 每条都来自已判定实验)

| 已闭合探针(判定文档) | 转译设计约束 |
|---|---|
| educate 6000iter 6/6 方向一致但幅度 < 同臂散布; 600s 净损=LS300 预算竞争(迭代压到 27%) | 教育机制方向正确, 病灶=预算竞争 → 只允许"每后代一次、预算封顶"形式; 先固定迭代口径验证再进 600s(M3 之后) |
| cx 族 = seed 方差放大器(散布 204); SP 池 83-88% 重复列 = 档案自同质化 | 裸交叉无多样性压力必失效 → 多样性贡献(dc)必须进成员选择/替换(M1 就位, M2 配合重组测) |
| pyvrp 分配 3seed 罚金 893.8/889.7/889.7 强吸引子 vs 自产漂移 2 倍; pr20 成本差主因=错配 | 外层重组的候选最小继承单位 = **车场分配模式**(M2 判别实验 B 臂), 而非路由 |
| 罚域单轨迹无穿越(容量/TW 两族全闭) | 种群双空间(可行+罚域共存)是唯一未验的 FIS 形态 → M4 里程碑 |
| 单客户 redispatch 零移动; 错配 removal 反升(回归原盆地) | 分配级变异必须是子结构/分组级(重聚类), 不能是客户级局部操作 |
| 6000iter 重启从未触发; 600s 重启=有效多样性(admit 反转实证) | 成员刷新/重启语义按池级设计, 与迭代口径的停滞语义解耦 |

## 3. 目标形态

```
种群壳 (population_mode, 全部 config gated 默认关, 默认路径逐位不变)
 ├─ μ 成员池, 每成员 = 完整可行解 (初始解链从 engine.rng 取)
 ├─ 每迭代: 锦标赛选 1 成员 (fitness = cost − κ×best×dc, dc = 池内
 │   最小路由集 Jaccard 距离, 镜像 A2 fitness 量纲)
 ├─ 在该成员上跑标准 ALNS 迭代体 (destroy/repair/LS/接受/score/降温 —
 │   与 base 逐语义一致, M1 不含交叉/教育/罚域)
 ├─ 档案 = 精英池 (共享, 语义与 base 一致); 池级停滞 → 刷新最劣成员
 └─ M2+: 成员间重组 (A臂路由继承 vs B臂车场分配继承) ← 判别实验灵魂
      M3+: 预算感知教育 (每次 LS 封顶)
      M4+: 罚域成员双空间共存 (λ 按违规量分布校准)
```

## 4. 研究问题与论文形态(判别实验是灵魂, M1 是工程地基)

- M2 判别问题: **MDVRPTW 上种群 load-bearing 重组单位是"车场分配"还是"路由"?**
  - B 臂胜 → 分配盆地不可达坐实为"重组单位选错"(pr 基准无人报过) → 可独立成文;
  - A=B → 教育/多样性才是外层价值载体, cx 放大器结论被纠正 → 同样是知识;
  - 整体打平/超越 pyvrp(09-05 框架: 自有方法+实证+消融=贡献载体) → 论文主形态。
- 中间验收指标(每里程碑都测, 不等最终质量): 错配罚金向 pyvrp ~890 靠拢;
  跨 seed 分配一致性(漂移 2 倍→收敛); dump 解深 LS 盆地可达性改善。
- M1 定位: 只隔离"外壳语义"(预期 ≈ base)。三判据见预注册; M1 通过 = 壳无负效
  → 才有资格在 M2 上装重组; M1 负效显著 → verdict 修壳, 不上 M2。

## 5. 里程碑与关口(每关预注册 + verdict, 失败即收束进文档链)

| 里程碑 | 内容 | 口径/判据 |
|---|---|---|
| M1 | 种群壳最小形态(池+锦标赛+dc fitness+刷新, 无重组) | 6000iter × pr15/16/20 × s42-44 × {base, pop, popdc}; 判据=不劣于 base + dc 臂多样性≥纯成本臂 + 测试全绿 |

合并主线条件: M2 判别出方向(任一臂稳健)或 M3 起质量达门槛(配对差 > 同臂散布,
两口径一致) → 全量 pytest + verdict 链齐 → 合回 main。

## 6. 风险登记

1. pyvrp 即 HGS: 打平只算方法有效性证据, 论文增量靠 M2 判别结果 → M2 不可跳;
2. 600s 口径对 pyvrp 不公平(C++ 核 vs Python): 主 claim 域 = 固定迭代 + 结构指标;
3. 新旋钮泛滥: 全部机制 gated 默认关, 新增 config 键仅限壳本体(见 M1 spec),
   参数预注册死值;
4. M1 预期 ≈ base: 若 popdc 也无多样性增益信号 → 壳内多样性路径需修后再上 M2,
   不硬闯。
