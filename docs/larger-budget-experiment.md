# 更大预算实验记录 (A 方案): 负面结果

> 更新: 2026-08-08 · 目的: 验证 600s 预算能否让静态 gap 逼近 0

## 1. 实验结果

| 预算 | seed | pr01 cost | gap (权威 1083.98) | 说明 |
|---|---:|---:|---:|---|
| 120s | 42 | 1209.57 | +11.6% | 三轮修复后基线 |
| 120s | 42 | 1259.72 | +16.2% | 收敛分析 (波动 ±4%) |
| 600s | 42 | 1238.95 | +14.3% | 更大预算无改进 |

## 2. 关键发现 (负面结果)

1. **600s 预算没有改进** (1238.95 vs 1209.57, 甚至略差):
   单纯增加时间无法突破 ALNS 的收敛天花板;
2. **结果不稳定**: 同 seed 不同运行波动 ±4% (1209-1260),
   说明搜索陷入不同局部最优;
3. **档案仅 1 点**: 收敛分析中 120s 只产出 1 个 Pareto 点 —
   成本与排放共线 (COPERT 固定速度) 使双目标退化为单目标方向,
   Pareto 档案多样性差。

## 3. 根因分析

TW 硬约束 + 多车场分配使搜索空间复杂化, 当前 ALNS 配置
(k_min/k_max = 10-40%, 单路由 two-opt LS) 的扰动能力不足:
- destroy 规模不够大 → 无法跳出局部最优;
- LS 只在单路由内 → 无法跨路由/跨车场改进;
- 停滞检测 (stagnation_limit=2000) 可能过早触发重启。

## 4. 结论与后续

- **A 方案 (更大预算) 已证伪** — 不再跑 600s 全量 (2 小时无收益);
- **destroy 规模增大 (20-70% / 30-80%) 也无改进** (1259-1277, 均 5 辆);
- **TW-aware 初始解方向证伪**: 最近邻→TW 修复后初始解 1991.59 (6 辆),
  起点过高, 120s 后仅 1526.74 (gap +40.8%) — 严格 TW 可行构造过度绕路;
- **关键发现**: 权威解 warm-start (8 辆) 后 ALNS 保持 1083.98 零退化 —
  引擎本身能保持好解, 瓶颈是初始解质量与车辆数探索能力;
- **RVND 后 600s 复验 (2026-08-08)**: RVND 版 600s = 1121.81
  (gap +3.49% vs .res), 与 120s RVND (1118.84, +3.2%) 持平 —
  **5 倍预算无收益, ALNS+RVND 已达能力天花板** (6 辆, 车场 [1,2,3]);
  逼近 HGSADC BKS (1074.12) 需 HGS 级机制 (车辆数显式优化+种群进化);
- **结论**: 120s 预算下最近邻起点 + 四轮改进配置 (gap +1-5%) 已是
  ALNS 当前能力的最优; 逼近权威解需全新搜索机制 (车辆数显式优化 /
  多起点多样化 / path relinking), 超出本文范围;
- 论文如实报告: 120s 预算 gap +1-5% 为 ALNS 收敛能力边界;
  pyvrp 官方 1h gap 0.69% 作 SOTA 参照。
