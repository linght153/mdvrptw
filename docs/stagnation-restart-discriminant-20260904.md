# 停滞重启判别 (600s): admit 反转 + 口径依赖的混杂界定 (2026-09-04)

衔接: A2 小规模判定发现 archive.add 拒收耦合 stagnation_count。本判别测
"放宽准入 → 少重启" 在 600s 预算口径下的效应。
数据: base = sp_pool_pr20_s42.json (既有, best 3177.86, stagnation_limit
300 → 重启阈值 100, 重启频繁); admit = sp_pool_pr20_s42_admit.json (新跑,
probe_sp_collect.py 第 4 argv admit, best **3253.24**)。同 seed 42 同配置
只差 archive_admit_relaxed。

## 结果与反转

| 口径 | base | admit | 效应 |
|---|---|---|---|
| 6000 iter (阈值 2000) | 3307.93 | **3185.89** | 少重启 +3.7pp (好) |
| 600s (阈值 100) | **3177.86** | 3253.24 | 少重启 −2.4pp (差) |

**方向反转**: 重启频率的效应依赖预算口径。600s 下重启 = 有效多样性源
(多轨迹采样), base 600s 平台质量**依赖**重启; admit (几乎不重启) 单轨迹
卡 3253。与逃逸 V1-V6 自洽: base 600s 已内嵌频繁重启, "更多/更强重启"
无增量 ≠ 重启无价值。

## 混杂界定修正 (更新 A2 判定)

1. **6000 iter 口径** (population_ab 30-run 全部 + 今天 A/B): base 重启阈值
   2000, 重启 0-2 次吃预算 → div/admit 的"收益" = 少重启 (短预算下重启是
   净负担)。div −0.70pp 归因 (已作废的"多样性裁剪") 进一步修正为
   "重启频率差" — 该口径全部臂间对比都含此混杂。
2. **600s 口径** (connectivity/SP/教育列全部探针): 单臂 base, 无臂间对比;
   平台数字 (pr20 3177.86 等) 含重启多样性但**不涉"重启浪费"质疑** →
   "结构生成稀缺" 系列结论的底座**依然成立** (解已含多轨迹采样)。
3. **div 的 600s 复验预期反转**: div = 放宽准入 + 裁剪 → 600s 下少重启 →
   预期 ≈ admit 水平或更差 (负于 base)。population_ab 判定中 "div 需 600s
   复验" 的保留条款实际指向**负结果** — 待跑确认。

## 修复候选重估 (stagnation 与档案解耦)

原动机 (6000 iter 免费午餐) 成立, 但修复必须保留 600s 的重启多样性:
- 修复 = stagnation 计数改 **current 无改进迭代** (非 archive.add 成败):
  current 真停滞才重启 → 6000 iter 拿 admit 收益 (current 持续微改进不
  重启) + 600s 保留重启 (平台期 current 停滞 → 仍重启, 时机更准)。
- 两全候选, 但需实现 + 双向验证 (6000 iter 与 600s 各 ≥2 实例), 且改默认
  行为 → 锁存更新 + 全量重评 (120 PASS 锁存含 tight 300iter? 需核查锁存
  配置的重启阈值触发)。
