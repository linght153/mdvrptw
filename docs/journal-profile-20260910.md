## 6. 审稿流程与周期

- 流程：主页投稿 → **预审**（达不到要求可退稿/驳回重投）→ 初审合格获稿号 → **形式审查**
  （形式要素 + 查重；严格，"形式审查极其严格"为用户共识）→ 专家审查（多轮）→ 终审。
- 周期：官方"外审预计约 2 个月"；小木虫用户实测**平均约 2.8-3 个月**；常见结果为"修改后录用"。
- 修改要求：每轮须提交**正式的修改说明报告**（答复不得直接写进正文），未充分响应不进复审。

## 10. 投稿操作清单（录用前）

1. 官网注册 → "投新稿件" → 勾选投稿确认书 →（阅读版权转让协议，正式协议录用后提交）；
2. 上传 **Word** 稿（要素齐全即可，无须按刊版式排版）；
3. 基金项目若系统无法添加，**在论文首页脚注标注清楚**；
4. 形式审查（要素 + 查重）→ 专家审查（多轮，逐轮提交修改说明）→ 终审 → 拟录用通知
   （此时确认版面费与协议）。

## 11. 风险清单

- 形式审查严格：**要素缺一即可能被退**（首页脚注、中图分类号、英译文献、图表英译等）；
- 黑白印刷：所有图不得以颜色作唯一区分（已达标）；
- 数学符号规模：须知明确建议"控制全文数学符号规模"（我们符号量中等，可再核）；
- 超页费用：以拟录用通知为准，预算需导师确认（项目预算 4,000 元，常规区间可能不够）；
- 一稿一投：退路刊仅在拒稿后转投。
