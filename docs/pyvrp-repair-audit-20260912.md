# pyvrp 对照转换通道审计 (2026-09-12) — 统计公平性修正

## 起因

用户据经验判断 "MA/base/pyvrp 实验结果不准确", 要求核查统计层缺陷。
审计确认: **pyvrp 侧转换管道存在系统性压分缺陷**; 原 J6 结论 ("自产在 pr15/16
反超 pyvrp") 为转换假象; 修正后 = **pyvrp ≥ 自产 (三实例)**, 回到与文献经验
(HGS 短预算强势) 一致的状态。

## 审计过程与证据

1. **独立复算 raw pyvrp 解** (scripts/stats_audit.py, 临时脚本):
   - 探针 JSON 的 `routes` 字段 = 修复前原始路由 (probe_pyvrp_wide.py 注释确认);
   - 独立重算距离 + 违规数: **违规数与 recorded `d_col_violations` 逐位一致**
     (口径校验通过, raw 数字可信);
   - raw 均值: pr15 **2441.4** / pr16 **2850.8** / pr20 **2989.3**
     = 贴 BKS +0.18~0.50% (与文献/旧版"破 BKS"经验一致)。
2. **修复损失量化** (raw → 原 std_cost): pr15 2811.3 (+15.2%) / pr16 3105.4
   (+8.9%) / pr20 3599.7 (+20.4%)。损失量级与违规条数无关地大 → 指向修复通道。
3. **通道缺陷定位**: `combined_excess_repair` 目标 = 联合超额 (TW+duration),
   **无距离项**; 单步调用后无距离再优化 → 消除微量超额 (数秒~百秒级) 可付出
   数百距离代价 (pr20 s1 单例 +1080)。
4. **对称性证据**:
   - 自产解 (B8 dumps): 独立复算逐位一致 (0.0000) + RVND 打磨增益 **0.0000**
     (5/5 已处于局部最优);
   - base 臂抽查 (pr15 s42 复跑): 成本=纯距离 (独立复算差 0.0000), 打磨增益
     **0.0000** → 自产两臂解状态对称;
   - 原转换下 pyvrp 解距其局部最优 +404~+642 (s1 样例) → 对照不对称实锤。

## 修正协议 (标准转换, 对称定义)

```
raw pyvrp 解 → ① 违规修复 (引擎同链 _enforce_feasibility, 可复现: 30/30
                与 recorded std_cost 逐位一致)
             → ② 可行域内 RVND 打磨至局部最优 (多轮不同 rng 直至无增益)
```

- 自产解同处于 RVND 局部最优 (B8 5/5 + base 抽查证据) → **两侧解状态对称**;
- 确定性: v2 复核 (修复 3 种子对照) 30/30 结果逐位相同 — 修复为确定性下降路径
  (未触发随机扰动), 转换值稳定可复现;
- 实现: `scripts/pyvrp_polish_correct.py` (+`_v2.py` 确定性复核);
  输出 `results/durfix/pyvrp_wide_corrected/`。

## 修正结果

| 实例 | raw (原生) | 原转换 (仅修复) | **标准转换 (入表值)** | 残余转换代价 |
|---|---|---|---|---|
| pr15 | 2441.4 | 2811.3 | **2577.2** | +135.9 (确定性) |
| pr16 | 2850.8 | 3105.4 | **2961.3** | +110.6 |
| pr20 | 2989.3 | 3599.7 | **3175.7** | +186.4 |

逐 seed 残余范围 +35~+438; 残余为**确定性转换代价** (下降路径选取, 未触发扰动),
方向为对 pyvrp 保守 (任何更优转换只会降低其转换值) → 据此的对照结论稳健。

## 教训 (沉淀)

- **跨算法对照中, "解转换管道" 本身是公平性组件**: 必须与自产解受同一标准
  (修复 + 打磨至局部最优), 并以独立复算留证; 转换残余代价如存在须量化披露。
- **可行化/修复类代码必须明确目标口径**: 距离盲的可行化在紧约束实例上引入
  +9~20% 的系统偏差, 足以翻转结论。
- **"经验与数据矛盾" 是有效预警**: 用户经验 (pyvrp/HGS 应强于自研 ALNS 于短预算)
  与本批数据 (自产反超) 的矛盾直接指向转换层缺陷 — 任何与文献常识冲突的"胜出"
  都应先查对照管道。
- 修复通道的距离盲性对自产搜索的潜在影响 (in-loop, 后续数千迭代再优化, 影响
  有限) — 记录待查, 不阻塞判定。
