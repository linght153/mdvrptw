## 机制结论 (修正方向图景)

1. **裸交叉 (A1) 死因坐实**: 后代列 ∈ 档案池 → SP 上界封顶; 互补交叉的价值
   不在交叉本身而在教育改造 (cross 阶段 d=1.0 完全互补 = 全量重插大破坏,
   skip 84%、教育后 +10~30pp — cx 诊断的极端版, 互补度过高同样无效)。
2. **在线单轨迹吃不到列池价值**: 互补列分散在不同后代解里, 单轨迹永远只走
   一条解; SP 离线拼接是唯一同时利用多后代列的机制 → A1+教育线的可行形态 =
   **教育列池 + 周期性精确 SP 跳板** (memetic-with-exact-education 的列池版),
   非"在线交叉迭代" (cx 实验形态)。
3. **量级诚实标注**: −0.1035pp ≈ 剩余 gap (6.5%) 的 1.6%, 单列贡献; 回答的是
   "机制存在性" (教育能生成有组合价值的池外列), 不是平台突破。SP 增益随
   教育轮次/池规模的增长曲线未测 — 若 5 轮进化仍饱和 ~0.1pp, 教育线 = 论文
   诊断素材而非主线; 若 ≥0.5pp 则有平台价值。
4. **研究支撑排序更新**: A2 (多样性 fitness, div 6000 iter 实绩 −0.70pp /
   pr15 −1.81pp) > A1+教育列池形态 (0.1pp 初值, 待轮次曲线) > L1 多 seed 池 (关闭)。
