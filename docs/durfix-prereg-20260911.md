## 2. 判定准则 (先于结果冻结)

**P0 硬门槛 (全部批次)**: 每份入表解必须通过 scripts/verify_solution_constraints.py
全项核验 (覆盖/容量/车队/往返同场/客户 TW/车场最迟返回/最大路线时长/成本)。
任一份失败 = 实现问题 → 修复重跑, 不得带病入表。

**J1 (核心 claim, 10 种子)**: popcxge−base 配对差, 三实例逐实例报告, 与旧值对照分三态:
- 保持: 方向为负且负向种子数 ≥ 8/10, 幅度同量级 (缩水 <50%);
- 缩水: 方向为负但负向 7-8/10 或幅度缩水 ≥50%;
- 反转: 任一实例非负。→ 论文按实际三态如实改写, 不预设保留原 claim。

**J2 (重组单位)**: 簇臂 vs 路由臂三实例三种子均值, 三态同 J1。
**J3 (C4 开关) / J4 (参数扰动)**: 记录性, 无判定; 与旧批对照更新论文对应段。
**J5 (等墙钟)**: pr16/pr20 方向报告; pr15 记录。
**J6 (600s 平台)**: 与 pyvrp 同预算差距重算; 披露与旧值对照。
**J7 (破界/低于参照值类观察)**: 旧观察全部作废。新结果若再现"低于所引参照值"且解通过
P0 核验 + 独立重算 + BKS 时效复检 → 仅以"记录性观察 + 自限注"呈现, 不作正式宣称;
否则删除相关段落。
