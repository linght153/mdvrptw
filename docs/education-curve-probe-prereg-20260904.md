# 教育列池轮次曲线探针预注册: A1+教育线最终去留 (2026-09-04)

衔接: 列池外探针 L2 (教育列 SP −0.1035pp 破 H3 上界, 单列贡献) → 未决问题 =
增益是**存在性饱和** (~0.1pp, 论文诊断素材) 还是**随轮次增长** (≥0.5pp,
平台价值)。本探针 = 多轮教育列池进化 + 每轮精确 SP, 画增益-轮次曲线。

## 假设

H-E: 教育列池增益随轮次单调增长 (每轮新教育列 + SP 组合解回流双亲池 →
更优双亲 → 更优教育列 → 池更优), 8 轮内达 ≥ −0.3pp; 若 3 轮内饱和
≤ −0.2pp → 教育列源枯竭, A1+教育线关闭。

## 方法 (全部管线复用, 单进程确定性)

- 初始列池: merged = s42∪s43 池 (125 列) — L1 已证纯列无增益, 后续增益
  全部可归因于教育列。
- 初始双亲池: s42 20 解 + s43 20 解。
- 轮 r = 1..8, 每轮:
  1. 双亲对 = 双亲池解间 Jaccard 距离 top-10, **窗口 0.35 ≤ d ≤ 0.85**
     (L2 修正: d=1.0 完全互补 = 全量重插大破坏 skip 84% 无效; 有效区间 =
     中度互补), 贪心去重。
  2. 每对 K=2 交叉 (route_copy 0.6) + RVND 教育 → 后代列 (序列级去重)
     入全局池; 教育后 cost < 池内最佳×1.05 的后代解入双亲池 (保结构多样性)。
  3. SP (当前池) → obj_r; 若 SP 解成本 < 双亲池 best → SP 组合解入双亲池
     (memetic-with-exact-education 的回流)。
- 输出: 每轮 {pool_cols, new_cols, sp_obj, gain_pp_vs_best, n_parents, wall};
  曲线落盘 results/education_curve_pr20_analysis.json。
- 判定基准: best = min(s42 best 3177.86, s43 best 3303.58) = 3177.86。
  (600s s43 轨迹未达 s42 水平 — 时间预算方差记录在案; 曲线增益 vs 3177.86)

## 判定阈值 (pr20 主判)

- **支持 (平台价值)**: 8 轮末 SP 增益 ≤ −0.5pp 且曲线单调趋势明显;
  或末值 ≤ −0.3pp 且后 3 轮仍在下降 (未饱和)。
- **边缘**: 末值 ∈ (−0.3, −0.2]pp — 视曲线形状: 仍在降 → 延长轮次再判;
  饱和 → 诊断素材。
- **关闭**: 末值 > −0.2pp 且 3 轮内饱和 → 教育列源枯竭 (每轮新池外列骤降
  佐证), A1+教育线最终关闭, 研究重心转 A2 (多样性 fitness)。

附加机制报告: 每轮新列数 (枯竭信号)、SP 解回流后的双亲距离分布、
总 wall。

## 执行纪律

- 单进程串行; rng 固定 (SEED_BASE + 轮×K) 逐位可复现; 重跑冒烟校验一次。
- 结果落盘 + 判定文档; 若判定"支持"需注明 600s 级复验仍待做 (曲线是
  固定轮次口径, 与 600s 平台判定差一步)。
